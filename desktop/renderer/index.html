What you see

Start with sessions and their status. Add details when you need them.

Applies to the session panel and dashboard. In a project workspace, use Settings → What you see.

Where Ocelin lives

Choose any combination. Closing a window keeps monitoring active.

The taskbar text strip keeps running counts and allowance visible inside the Windows taskbar using the optional Taskbar Widgets host. Experimental native cards show details when hovering over the app icon. You can enable either or both.

Percentages are per provider. With multiple profiles, the lowest reported value is shown; * means some readings are unavailable. Open the panel for each account and reset time.

Appearance
Session history

Active sessions appear first. Clear older finished and stale entries from Ocelin’s views; a session returns when it has new activity. This leaves the original Codex and Claude conversations intact.

Notifications

Windows notification settings also apply. “Turn finished” means the observed response ended.

Sources & integrations

Transcript monitoring works immediately. Optional hooks improve permission and lifecycle signals. Hook changes are previewed before applying.

WSL: choose a transcript folder under \\wsl.localhost\DISTRO. For remote machines, sync transcripts to a local folder and add it as a read-only mirror.

Account profiles

Connect another signed-in Codex or Claude Code profile to see its allowance and local sessions. Select its configuration folder, such as .codex-work or .claude-work.

Each card reads the current sign-in in that profile. Saved sessions show their source profile; their original account may be unknown. App-only sign-ins and temporary terminal tokens are not automatically connected.

About Ocelin

A local companion for Codex and Claude. No account or API key needed. Click a conversation to continue in its owning app. Press Ctrl Alt O for the quick panel. Transcript previews stay on this computer.

App memory & CPU

Private RAM currently in use by recognized Codex, Claude and Ocelin processes, including their child tools. Desktop apps share processes across projects; these totals cannot be divided reliably between sessions.
