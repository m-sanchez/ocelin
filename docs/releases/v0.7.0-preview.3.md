# Ocelin 0.7.0-preview.3

An unsigned experimental preview for Windows x64, with a matching browser package. Updates are manual. The earlier 0.6.8 preview remains available as a fallback; neither is a stable release.

- New installations start with a provider choice and a recent conversation to preview before requesting a return to Codex or Claude.
- After requesting an open, the guide asks you to check the destination. Choosing another conversation opens History; Skip persists, and Settings can reopen the guide.
- Missing providers, unavailable sources and preview-only remote/WSL records have separate guidance. Hidden sessions and subagents are excluded from suggestions.
- Explicit previews support keyboard focus and return it when closed. Existing installations retain their established view.
- README and website tour assets use the same version and synthetic capture set, with file hashes in the screenshot manifest.

All 743 tests, the server self-test, focused first-return tests, and source and packaged Electron smoke checks passed. Packaged executable and installer branding checks passed for all nine icon sizes. The smoke covers both providers by keyboard and simulated native dispatch; it does not establish that either provider rendered the requested conversation or that an independent person completed the workflow.

Local session monitoring does not require a model request. Optional Ask Ocelin sends a question and a compact, secret-scanned snapshot through Claude Code to its configured model service. Existing unsigned-update, source-profile, remote/WSL and hardware-validation limits still apply; see [Windows compatibility](../WINDOWS-DESKTOP.md#validation-and-preview-limits).
